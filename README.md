# 🎼 Amenora – Kompozytorka (Test Site)

This is a **test website** created for a fictional composer named **Amenora**.

> **Note:** This project is a test/sandbox site. All information about the composer and her work is fictional and created for demonstration purposes.

## ✨ About the Project

The site serves as a simple, elegant business card for a composer, showcasing:
- A short bio
- Areas of musical work (film, theatre, concert, electronic)
- Example projects and stats
- A gallery with randomly loaded anime-style images
- Contact information and links to social media

The design is inspired by the **"Glam Blue / Genshin Glass"** aesthetic – a glass-morphism style with blue tones.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Glass-morphism, custom fonts)
- **GitHub Pages** – hosted on [GitHub Pages](https://pages.github.com/)
